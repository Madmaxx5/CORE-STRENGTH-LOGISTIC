# Core Strength Logistics LLC Website

GitHub Pages-ready static website.

## Upload to GitHub
Upload the CONTENTS of this folder to the root of your repository (not the ZIP itself).

Required root files:
- index.html
- services.html
- about.html
- rates.html
- contact.html
- 404.html
- CNAME
- assets/ folder

GitHub Pages settings:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
- Custom domain: corestrengthlogistics.com
